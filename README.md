# FarmaTech 💊

Sistema de gerenciamento de farmácia desenvolvido em Python e MySQL.

---

## 📌 Funcionalidades

- Cadastro de usuários
- Login de administrador e cliente
- Cadastro de produtos
- Listagem de produtos
- Pesquisa de produtos
- Carrinho de compras
- Controle de estoque
- Finalização de compras
- Relatório de vendas

---

## 🛠 Tecnologias utilizadas

- Python
- MySQL
- Git
- GitHub

---

## ▶ Como executar o projeto

### 1. Clone o repositório

```bash
git clone https://github.com/saintsflavo/FarmaTech_1.git
```

### 2. Instale as dependências

```bash
pip install mysql-connector-python
```

### 3. Configure o banco de dados MySQL

Crie o banco de dados e as tabelas necessárias no MySQL.

### 4. Execute o projeto

```bash
python main.py
```
